# Iterlay 对外文案

## 产品定位

免费开源的 AI 创作 App，把图片、视频与创作工作流放在同一张画布上。面向需要制作视觉素材的创作者、设计师和开发者；Agent 联动是可选能力。

## 中文

主标题：**图片、视频与创作工作流，一张画布串起来。**

一句话：Iterlay 是免费开源的 AI 创作 App，把图片生成、编辑、视频创作和素材整理放在同一张画布上。

简短介绍：生成图片、修改细节、制作视频，再把参考、版本和成品整理在同一张画布上。从一个想法到一套素材，接着做，不用来回搬。支持接入自己的模型服务，也能与 Codex、Claude Code 联动。

社区标题示例：我做了一个免费开源的 AI 创作 App：图片、视频和创作工作流，都在一张画布里。

## English

Headline: **Images, videos, and creative workflows. One canvas.**

Short description: Iterlay is a free, open-source AI creative app for generating images, editing, making videos, and organizing assets on one canvas.

Introduction: Generate images, refine the details, and make videos, with references, versions, and finished assets together on one canvas. Connect your own model providers, or bring Codex and Claude Code into the workflow.

## 表达边界

- “创作工作流”指参考 → 生成 → 修改 → 比较 → 视频创作 → 整理导出的衔接；可以手动操作或让 Agent 执行步骤。不要暗示已有通用节点编排、任意步骤自动执行或完整视频剪辑能力。
- App 免费开源，模型服务自行配置，模型调用由对应服务商计费。“自选模型”不能写成“自带免费模型”。
- 图生视频、文生视频、编辑与参考图支持取决于具体模型及接口；不承诺所有模型支持所有步骤。
- FIELD 当前案例证明图片创作和版本比较，不要把它描述成已有视频演示。介绍片的 AI 片头、配音和外部剪辑须按真实制作过程说明。
- 不宣称一键完成全部创作、保证效果、节省固定时长或已有大量用户；需要真实证据后才能使用。
