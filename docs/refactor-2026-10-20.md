## App 的领域职责

- `src/features/generation/create-video-generation-controller.ts`：普通视频的确认、提交、轮询、恢复和结果归属；保存前冻结原画板上下文，切板后不混读新画板节点。
- `src/features/video-sequence/`：编辑器模型适配、序列生命周期、变更、模板实例化和导出。异步响应受画板、序列身份及请求版本保护，关闭或切板后不重新弹回旧序列。
- `src/features/templates/`：模板库、收藏、应用、导入导出及从画板结果提炼模板。
- `src/features/generation/confirmation.ts`：共享的费用确认输入契约。

App 保留工作台组合、画板状态所有权与已有保存/撤销协调能力；没有复制出另一份画板数据状态。

## PromptDock 与翻译

- `assistant-instruction.ts`：独立的请求输入契约与执行流程，不再从 PromptDock UI 导入类型。
- `assistant-stream-handlers.ts`：流事件归并、完成、失败、取消及旧请求隔离。
- `use-assistant-history.ts`：历史请求、恢复、跨画板导航和并发响应保护。
- `use-assistant-branch-lifecycle.ts`：将会话恢复生命周期绑定到画板/模式/模板分支，保留 StrictMode 重放和切板取消。
- `use-assistant-panel-layout.ts`：拖拽、缩放、吸附、收展及事件释放。
- `GenerateActionButton`、`ProviderPicker`、`ReferencePicker`、`GenerationSettingsPicker`、`PromptToolbar`：独立展示组件。

生成按钮通过 `useUiText` 翻译，移除了对 `legacy-messages` 的静态引用。测试追踪完整静态依赖图，覆盖中文、英文冷启动、语言切换和已有英文标签。

网页验收发现历史虽已落盘、刷新后 UI 却可能丢失恢复结果：可变就绪状态触发 effect cleanup 取消读取，而分支“已初始化”判断阻止再次恢复。本轮已通过独立分支生命周期修复；真实网页验证刷新后历史消息可见，未重新请求模型。

## 主进程服务与协议

- `electron/application/assistant-session.ts`：助手请求准备、记忆与对话历史持久化。
- `assistant-request.ts`、`assistant-reference-image.ts`：输入校验及图片规范化。
- `board-import.ts`：画板包导入，重映射节点、连接、图片版本、历史、评论、收藏等本地引用。
- `asset-maintenance.ts`：跨存储引用收集、回收站保留与垃圾清理，并统一释放定时器。
- `electron/agents/completion-protocol.ts`：通用 Pi 消息转换和决策 JSON 解析；普通文本助手不再加载 MasterGo 集成。MasterGo 保留必要兼容导出，未强行合并两套 Pi SDK。

IPC 保留传输注册、来源校验及流交互生命周期，复用同一应用服务。原有持久化 schema、可信注册表、Worker 和 Abort 执行链保留。

反复刷新还暴露出 deep-link 的 ready 事件反复追加 destroyed 监听。本轮改为同一 WebContents 只注册一次，新增连续 20 次 ready、销毁释放及待处理链接恢复的行为验证，没有通过提高监听器上限掩盖问题。
