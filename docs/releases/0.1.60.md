从 0.1.59 升级，改进视频生成、AI 助手和 Coding Agent 集成，并优化应用启动。

- 视频生成按模型目录统一处理时长、画幅、清晰度、声音及首尾帧约束；界面与提交入口共享校验，减少无效请求。
- 改进 AI 助手生成结果反馈与对话恢复，生成未完成时提供明确提示。
- 优化启动模块加载与旧工作区迁移，减少重复扫描和启动阶段开销。
- Coding Agent 集成同时安装与同步 `iterlay-workspace`、`using-iterlay` 两个 Skill，完善 CLI 与应用内的使用入口。
- 更新中英文说明、开发文档和工作流示例。

安装包：
- macOS Apple 芯片：`Iterlay-0.1.60-arm64.dmg`
- macOS Intel 芯片：`Iterlay-0.1.60-x64.dmg`
- Windows x64：`Iterlay-0.1.60-x64.exe`
- Windows ARM64：`Iterlay-0.1.60-arm64.exe`

随附 `SHA256SUMS.txt`，用于校验下载文件。

保持永久免费开源，AI 调用费用由你连接的服务商收取。安装包未使用 Developer ID / Windows 代码签名，macOS 未公证。

平台限制：系统照片分层依赖 macOS 14+；按需下载的视频处理组件目前提供 macOS ARM64 版，其他平台需要自行配置 FFmpeg / FFprobe 才能使用依赖这些工具的本地处理功能。安装包构建及包结构检查不等同于各平台真机功能验收。

验证：完整 CI（类型检查、Lint、单元测试、生产构建）与隔离网页冒烟测试通过，四种安装包均通过包内容与体积审计。发布前校验安装包名称、版本及 SHA-256。
