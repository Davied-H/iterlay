# Iterlay 0.1.70

## 改进与修复

- 修复 CLI 和工具导入图片、视频时误用文本长度限制的问题，支持最大 20 MiB 的素材并改进错误提示。
- 修复助手模式切换入口及启用状态，优化提示词编辑器的显示与清除交互。
- 更新官网首页，新增中英文技巧页面；技巧内容经审核后才公开。

## Improvements and fixes

- Fix CLI and tool imports applying text length limits to images and videos; support media files up to 20 MiB with clearer errors.
- Fix assistant mode switching and enablement, and refine the prompt editor display and clear interaction.
- Refresh the website home page and add bilingual tips pages; individual tips are published after review.
