从 0.1.62 升级，完善 CLI 后台创作与服务商配置，优化图片编辑交互，并更新官网双语体验。

- CLI 默认自动启动隐藏后台服务，执行命令无需显示 App 窗口；`--no-launch` 仅连接已有服务。后台任务与前台窗口共享工作区，用户打开 App 时可切回前台。
- CLI 新增视频与独立 TTS 音频服务商配置：支持查看配置、添加或更新、设置默认、删除，以及选择和保存模型。密钥可通过环境变量或标准输入传入，配置查询不返回密钥。
- 服务商配置通过事务更新，减少并发修改相互覆盖；支持视频服务复用匹配的图片服务连接，并校验地址、协议类型与音频接口路径。
- 图片编辑建议与刷新入口整合到编辑工具栏；进入高级编辑或退出编辑前同步当前提示词，改进窄窗口下的生成参数展示，并简化提示词助手的编辑开场白。
- 官网补齐双语内容、浏览器语言识别与统一导航；语言开关支持键盘操作、减少动态效果和切换时保留阅读位置。更新图片、视频与创作工作流介绍及 FIELD 示例。

安装包：

- macOS Apple 芯片：`Iterlay-0.1.63-arm64.dmg`
- macOS Intel 芯片：`Iterlay-0.1.63-x64.dmg`
- Windows x64：`Iterlay-0.1.63-x64.exe`
- Windows ARM64：`Iterlay-0.1.63-arm64.exe`

随附 `SHA256SUMS.txt`，用于校验下载文件。

永久免费开源，AI 调用费用由你连接的服务商收取。安装包未使用 Developer ID / Windows 代码签名，macOS 未公证。

平台限制：系统照片分层依赖 macOS 14+；按需下载的视频处理组件目前提供 macOS ARM64 版，其他平台需要自行配置 FFmpeg / FFprobe 才能使用依赖这些工具的本地处理功能。

发布流程要求类型检查、Lint、单元测试、生产构建与隔离网页冒烟测试通过，四种安装包通过内容和体积审计，再校验版本、文件名与 SHA-256。离线模型测试、构建和包审计不等同于真实收费模型或各平台真机功能验收。
