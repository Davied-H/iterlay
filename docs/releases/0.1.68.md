# Iterlay 0.1.68

## 改进与修复

- 自定义图片模板支持 CLI 创建、查询、更新与复用，并与工作台共享保存和同步。
- 优化助手流式正文、执行过程折叠展示、输入建议与引用素材历史；创作会话支持自动命名。
- 修复助手决策格式错误后放弃执行的问题，保留工具能力继续纠正，并避免重复执行成功操作。
- 视频提示词正确进入视频生成流程；助手提交的视频任务新增持久化占位、状态跟踪及结果聚焦。
- 改进视频序列退出、播放定位、跨片播放与剪辑范围编辑。
- OAuth 回调等待令牌交换与凭据保存完成后再显示成功，并改善错误诊断。
- 精简画板图片边框，优化助手状态与操作布局。

## Downloads

提供 macOS Apple Silicon / Intel 与 Windows ARM64 / x64 安装包，附 SHA256SUMS.txt 校验文件。

## Improvements and fixes

- Share reusable custom image templates between the CLI and workbench.
- Improve streamed assistant replies, collapsible execution details, suggestions, reference history and automatic conversation naming.
- Recover invalid tool decisions without abandoning work or replaying successful operations.
- Route video prompts correctly and persist video task placeholders, track status and focus results.
- Improve sequence navigation, playback seeking, transitions and trim controls.
- Show OAuth success only after token exchange and credential storage complete.
