安装包：

- macOS Apple 芯片：`Iterlay-0.1.64-arm64.dmg`
- macOS Intel 芯片：`Iterlay-0.1.64-x64.dmg`
- Windows x64：`Iterlay-0.1.64-x64.exe`
- Windows ARM64：`Iterlay-0.1.64-arm64.exe`

随附 `SHA256SUMS.txt`，用于校验下载文件。

永久免费开源，AI 调用费用由你连接的服务商收取。安装包未使用 Developer ID / Windows 代码签名，macOS 未公证。

平台限制：系统照片分层依赖 macOS 14+；按需下载的视频处理组件目前提供 macOS ARM64 版，其他平台需要自行配置 FFmpeg / FFprobe 才能使用依赖这些工具的本地处理功能。

发布流程要求类型检查、Lint、单元测试、生产构建与隔离网页冒烟测试通过，四种安装包通过内容和体积审计，再校验版本、文件名与 SHA-256。离线模型测试、构建和包审计不等同于真实收费模型或各平台真机功能验收。
