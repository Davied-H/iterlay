从 0.1.61 升级，完善 Agent 修改请求、任务恢复与项目交付，并提供可供 HOL Guard 审查的 CLI 命令描述。

- 新增 Agent 修改请求：将区域蒙版或 Relax Flow 标注、修改要求与源图版本固定保存；支持原子领取、执行身份校验和结果回填，信息不完整时先澄清。保存请求本身不调用模型。
- 历史记录区分“复用提示词”和“还原任务”，保存原模型、编辑源与参考图片职责，避免把旧编辑任务还原成普通生图。
- 支持取消尚未提交的排队图片任务，保留应用级三任务并发；已提交任务不宣称远端取消或停费，中断后的不确定结果明确标为“结果未知”。
- 新增独立于当前预览版本的最终稿，以及固定源版本的项目交付配方：支持用途、相对目录文件名、尺寸、PNG/JPEG/WebP 编码，导出 ZIP 与 SHA-256 manifest，默认不覆盖文件。
- Provider 默认采用不提交生成请求的只读检查，分别展示联网、鉴权、模型目录与未验证的实际能力；主动测试图片生成需要单独确认可能产生的费用。
- 生成设置直接显示模型、尺寸、有效质量与张数；FIELD 完整示例新增源图、改色、场景、海报与交付章节，可定位真实图片和版本。
- CLI 提供离线可读的 Guard 描述文件，不安装 Guard、不改写 Agent 权限。生成、编辑、文件导出、配置安装与通用调用按影响区分；未知通用调用保持审查，整体决策仍由 Guard 全局策略决定。
- 官网补齐英文产品、功能、下载、配置和排障路径，明确官网预制体验、隔离网页开发与桌面本地保存的边界。FIELD 示例提供可导入画板与完整项目包。

安装包：

- macOS Apple 芯片：`Iterlay-0.1.62-arm64.dmg`
- macOS Intel 芯片：`Iterlay-0.1.62-x64.dmg`
- Windows x64：`Iterlay-0.1.62-x64.exe`
- Windows ARM64：`Iterlay-0.1.62-arm64.exe`

随附 `SHA256SUMS.txt`，用于校验下载文件。

永久免费开源，AI 调用费用由你连接的服务商收取。安装包未使用 Developer ID / Windows 代码签名，macOS 未公证。

平台限制：系统照片分层依赖 macOS 14+；按需下载的视频处理组件目前提供 macOS ARM64 版，其他平台需要自行配置 FFmpeg / FFprobe 才能使用依赖这些工具的本地处理功能。Guard 描述的上游收录、Guard 版本发布与用户主动启用是独立步骤，不代表自动安装或激活保护。

发布流程要求类型检查、Lint、单元测试、生产构建与隔离网页冒烟测试通过，四种安装包通过内容和体积审计，再校验版本、文件名与 SHA-256。离线模型测试、构建和包审计不等同于真实收费模型或各平台真机功能验收。
