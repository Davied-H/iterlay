# Iterlay 0.1.69

## 改进与修复

- 修复画板助手视频节点的自动布局，避免覆盖已有卡片，并在提交后稳定聚焦生成节点。
- 恢复普通助手模式切换状态，并补齐模式切换回调。
- 改进助手执行过程、视频任务状态与工作台交互反馈。
- 更新官网版本记录，支持发布说明中的 Markdown 配图。
- 发布流程接入 Iterlay 配图生成，按版本更新内容生成发布视觉素材。

## Improvements and fixes

- Avoid collisions when the board assistant places video generation nodes and keep focus on the stable generation node after submission.
- Restore regular assistant mode switching and complete its state callback.
- Improve assistant execution details, video task state handling and workbench feedback.
- Render Markdown images in website release notes.
- Generate a release visual from the version notes through Iterlay during the release workflow.
