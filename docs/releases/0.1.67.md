# Iterlay 0.1.67

## 改进与修复

- 画布视频默认预加载，无需先选中或悬停，保持不自动播放。
- 视频加载元数据后按真实宽高比显示，并保存尺寸与时长；切换视频版本时使用当前版本尺寸，避免竖屏视频沿用横屏布局。
- 多选图片、视频或 Canvas 节点时隐藏单节点工具栏，避免遮挡批量操作；图片与视频混选时分开显示批量操作栏。

## Downloads

提供 macOS Apple Silicon / Intel 与 Windows ARM64 / x64 安装包，附 SHA256SUMS.txt 校验文件。

## Improvements and fixes

- Preload canvas videos without requiring selection or hover, without autoplay.
- Fit video nodes to decoded dimensions and persist dimensions and duration. Use the active version’s dimensions when switching versions.
- Hide individual video and code canvas toolbars during multi-selection, and separate image and video batch actions to prevent overlap.
