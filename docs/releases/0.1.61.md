从 0.1.60 升级，新增插件工作区与短剧助手，更新创作入口和官网体验。

- 新增插件 SDK、插件安装管理与独立工作区，内置短剧助手，支持故事、角色、分镜、剧本编辑和 AI 助手协作。
- 短剧助手支持草稿恢复、运镜编辑和画面／网格／列表切换，优化分镜布局与操作入口。
- 更新创作首页的对话与任务展示，支持配置 CLI 默认生成画板。
- 改进视频生成占位状态与任务恢复，完善画板保存及插件数据隔离。
- 官网更新交互案例、下载页面与功能 Wiki，支持功能搜索、深链接和自动巡览。

安装包：
- macOS Apple 芯片：`Iterlay-0.1.61-arm64.dmg`
- macOS Intel 芯片：`Iterlay-0.1.61-x64.dmg`
- Windows x64：`Iterlay-0.1.61-x64.exe`
- Windows ARM64：`Iterlay-0.1.61-arm64.exe`

随附 `SHA256SUMS.txt`，用于校验下载文件。

保持永久免费开源，AI 调用费用由你连接的服务商收取。安装包未使用 Developer ID / Windows 代码签名，macOS 未公证。

平台限制：系统照片分层依赖 macOS 14+；按需下载的视频处理组件目前提供 macOS ARM64 版，其他平台需要自行配置 FFmpeg / FFprobe 才能使用依赖这些工具的本地处理功能。安装包构建及包结构检查不等同于各平台真机功能验收。

发布流程要求完整 CI（类型检查、Lint、单元测试、生产构建）与隔离网页冒烟测试通过，四种安装包均通过包内容与体积审计，再校验安装包名称、版本及 SHA-256。
