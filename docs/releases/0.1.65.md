# Iterlay 0.1.65

本版本将 Canvas 扩展为可运行的代码创作节点，并集中改进创作助手与工作台体验。

## Canvas 代码工作区

- 新增独立 Canvas 节点，支持 HTML、React JSX 和 Vue 单文件组件。
- 支持隔离沙盒预览、点击预览自动运行、运行/停止状态切换。
- 接入 CodeMirror 代码编辑器：语法高亮、行号、折叠、自动缩进、括号匹配和格式化。
- 新增 Console 调试台，可查看日志、错误和表达式结果。
- 新增桌面、平板、手机及自定义预览尺寸，支持横竖屏切换。
- 支持 AI 创建和修改 Canvas，并通过代码版本校验避免覆盖手动编辑。

## 工作台体验

- 精简 Canvas 节点标题、工具栏和运行控件。
- 移除主顶部工具栏中的修改请求与项目交付入口。
- 移除创作助手中的对话规划/直接生成模式切换。

## 验证

- 通过相关单元测试、TypeScript、ESLint、生产前端构建和网页模式验证。
