# 开源版与后台的连接边界

## 默认离线运行

应用不再内置商业后台地址。`ITERLAY_LICENSE_API_URL` 未设置或为空时，不发送产品统计请求。模型服务、更新检查等独立连接仍按各自配置运行。

灵感来源维护在 `shared/inspiration-sources.json`，包含名称、站点链接、分类、描述、启用状态、排序和内嵌图标。初始 18 个站点与 13 个图标复制自 NAS 上部署的 Iterlay Manage 服务（2026-10-19），不依赖旧后台的列表或图标接口。新增或修改后重新构建应用即可；打开站点仍会访问对应外部网站。

## 模板投稿与反馈

统一使用 [GitHub Issues](https://github.com/Davied-H/iterlay/issues)。应用只打开预填草稿，由用户登录 GitHub 并确认提交，不自动创建 Issue。

- 模板详情的“投稿”入口提供本地导出与 Issue 草稿。用户检查导出文件中的提示词和示例图，将 `.itt` 压缩为 ZIP 后作为附件上传；讨论与处理进度在 Issue 中跟踪。
- 浮动反馈组件继续使用 GitHub Issues，不调用原反馈接口、不自动截图上传。
- 旧模板投稿、审核查询与反馈 IPC 保留兼容入口，但不再连接商业托管服务。

## 可选统计 API

需要统计时，在启动应用前显式配置 API 根地址，例如：

```bash
ITERLAY_LICENSE_API_URL=https://your-backend.example/api/v1 pnpm dev
```

配置后，开源版向 `POST <API根地址>/analytics/anonymous-events` 发送事件。匿名 ID 是本次应用进程生成的随机值的 SHA-256，进程内保持一致、重启后更换，不采集设备指纹、不依赖商业授权签名。它用于会话级统计，不能据此计算跨会话的独立用户数。网络失败不影响工作台操作。

## 在线分享暂不开放

`shared/sharing-availability.ts` 中的 `ONLINE_SHARING_AVAILABLE` 当前为 `false`。设置开关、画板快速分享、侧栏分享管理、微信表情二维码入口均隐藏；下载文件、图片和微信表情的分享 IPC 在创建本地服务器前直接拒绝，分享链接导入也会在请求网络前拒绝。旧设置中保存的开启状态不能绕过限制。

本地导出继续使用；微信表情导出后可打开文件夹，通过微信文件传输助手发送到手机。

后续开源后台时，需要完成服务端部署配置、开源版身份/签名协议、分享会话生命周期和集成验证后，再解除功能开关。仅配置统计 API 不会恢复在线分享，也不会恢复商业授权服务。
