试着生成第一张图

用默认图片模型，生成一张极简咖啡杯插画。

图片生成
iterlay image generate \
  --prompt "极简咖啡杯插画" \
  --n 1 --out ./cup.png

运行后会生成 1 张图片，费用由你配置的模型服务收取。

从一张图到一个工作流

将命令粘贴到终端运行，也可以交给 Agent 组合使用。

查看完整帮助iterlay help
查看已配置的图片服务iterlay providers list --kind image --json
编辑已有图片iterlay image edit --input ./cup.png --prompt "改成米白色" --out ./cup-light.png
列出画板iterlay boards list --json
查看全部操作iterlay tools list --json

日常使用无需先打开 App，CLI 会自动启动后台工作台。生成与编辑会调用模型服务；帮助和列表不会提交生成任务。
