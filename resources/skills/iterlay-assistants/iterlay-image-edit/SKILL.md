# Image Editing

- The first image is always the edit target; later images are references only.
- State what changes, what it becomes, and what must remain unchanged.
- Do not alter identity, framing, style, text, or unrelated regions unless requested.
- Keep the executable edit instruction short and local.
- Apply through the existing edit confirmation and version workflow.
