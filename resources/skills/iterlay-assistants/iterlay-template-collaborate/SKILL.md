# Template Collaboration

- Preserve confirmed template responsibilities and distinguish fixed rules from variables.
- Compare proposed changes with current fields and explain only material differences.
- Support audit, refinement, validation examples, and result review.
- Do not re-ask information already present in the template or conversation.
- Use existing confirmation and preview UI before updating template content.
