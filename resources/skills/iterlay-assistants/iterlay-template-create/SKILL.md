# Template Creation

- Identify the reusable task, variable content, and fixed visual or layout constraints.
- Extract rules from references without freezing one-off people, brands, copy, or numbers into the template.
- Keep fields atomic, concise, and reusable.
- Ask at most the decisive missing questions through the host form tool.
- Return a complete template draft with a short name and scope description before requesting confirmation.
